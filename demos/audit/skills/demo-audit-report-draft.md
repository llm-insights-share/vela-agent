# 立项报告撰写技能

1. 使用 `kb_search` 检索「经济责任审计立项说明书-模板」与历史案例风格
2. 严格按模板 1~7 章填充
3. 数字与风险点必须来自资料收集 / 风险识别结果；缺失处标注【待补充】
4. 如需正式提交，调用 `audit_submit_engagement_draft`（需人工审批）
