# 会议纪要与督办管理办法（星河控股 · Demo）

> 结构参考业界「会议纪要—任务分派—督办台账—完成验收」闭环 SOP（行政办公室会议督办实践），并结合企业行政流程规范中「会后 24–48 小时出纪要」要求改写为星河控股内部制度摘要。

## 1. 适用范围

公司级例会、跨部门专项会、客户复盘会等需形成可执行决议的会议。纯信息同步会可不建督办，但需保留简要记录。

## 2. 会前

1. 发起人至少提前 **1 个工作日** 提交会议室预约（主题、时长、人数、设备）。
2. 议程不少于 3 项时须附材料清单；超过 90 分钟须拆会或设分组。
3. 行政专员确认会议室状态：`available` 方可锁定；`maintenance` 禁止占用。

## 3. 会中

- 主持人控制议程；记录人按「议题 / 结论 / 待办」三段记录。
- 形成「需有人执行、需有完成时间、需有结果验收」的事项，必须进入督办台账。

## 4. 会后纪要

| 要求 | 标准 |
|------|------|
| 出纪要时限 | 会后 **24 小时内**（最迟 48 小时） |
| 必备字段 | 主题、时间地点、主持人、参会人、决议、待办（责任人+时限） |
| 发布 | 主持人确认后方可 `published` |
| 分发 | 参会人 + 决议涉及部门 |

## 5. 督办闭环

1. **当日录入**：纪要发布当日将待办写入 `action_items`。
2. **周更**：行政主管每周至少更新一次；P0 事项按日关注。
3. **销项标准**：结果 + 证据 + 时限 + 影响 + 合规，五项核验通过后方可 `done`。
4. **升级**：逾期 >2 天且无证据，升级至责任人上级与行政主管。

## 6. 禁止事项

- 只转发纪要不拆任务。
- 口头完成、无证据销项。
- 擅自修改已发布纪要决议（须发修订版并标注变更）。
