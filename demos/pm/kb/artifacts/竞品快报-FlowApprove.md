# 竞品快报：FlowApprove vs 星河审批中心（Demo 制品）

**复盘日**：2026-09-01  
**作者**：林悦  

## 一句话结论

FlowApprove 赢在移动与模板；我们应在 **审计导出 + HITL/Agent 协同** 打差异化，而不是纯功能对标。

## 功能对照（摘要）

| 能力 | FlowApprove | 星河审批中心 |
|------|-------------|--------------|
| 待办聚合 | full | MVP 建设中 |
| 批量导出 | partial（仅管理员） | 规划中（BL02） |
| 审计日志 | none | 规划中 |
| HITL / Agent | none | 可复用 Vela 能力 |

## 对 backlog 启示

1. **必须跟进**：筛选、导出（客户续约卡点）
2. **差异化**：审计日志完整度、与 Vela Agent 的人机协同
3. **不跟进**：短期内堆砌 FlowApprove 级模板市场

## 证据

- 访谈 RI01：「你们要是能一键导出，我就续约」
- 反馈 FB01 工单主题=导出
