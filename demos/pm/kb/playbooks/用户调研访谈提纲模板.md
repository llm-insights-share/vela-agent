# 用户调研访谈提纲模板（星河控股产品部 · Demo）

> 结合公开用户研究模板（访谈指南 / Persona）与「问卷+行为数据三角验证」思路，提供半结构化访谈骨架。

## 1. 会前

- 研究问题（1 句）
- 招募标准与排除标准
- 知情同意与录音说明

## 2. 访谈结构（45–60 分钟）

1. 破冰与背景（5′）
2. 当前工作流还原（15′）——「上次你怎么完成审批/续约？」
3. 痛点深挖（15′）——频率、影响、现有 workaround
4. 期望蓝图（10′）——魔法按钮问题；可接受代价
5. 验证假设（10′）——对方案草图的反应
6. 收尾（5′）

## 3. 纪要字段

- Persona / 受访者
- Jobs-to-be-done
- 痛点列表（可映射 backlog）
- 原话金句（≥1）
- 跟进假设与置信度

## 4. 三角验证

主观说法须尽量对照行为数据（DAU、漏斗、工单主题）。偏差 >30% 标记「认知偏差」，需补访。
