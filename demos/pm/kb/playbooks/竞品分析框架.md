# 竞品分析框架（星河控股产品部 · Demo）

> 参考 2026 年产品方法论中「多维竞品矩阵」（功能之外纳入技术/生态/商业/用户情感）与公开竞品分析模板，收敛为可执行的一页纸 + 详表两层产物。

## 1. 分析层级

1. **战略层**：品类定位、定价、目标客户、增长打法
2. **能力层**：核心功能矩阵、集成生态、AI/自动化深度
3. **体验层**：关键路径步数、移动端、学习成本
4. **证据层**：客户原话、公开案例、更新日志

## 2. 功能矩阵评分

| 分值 | 含义 |
|------|------|
| full | 完整可用且可规模化 |
| partial | 有能力但不完整/限制多 |
| none | 无 |

## 3. 输出物

### 3.1 销售一页纸（对外）

- 我们 vs 主要竞品的 3 个差异化卖点
- 1 个客户可验证的证据（案例/指标）
- 明确「不打」的战场（避免无效比价）

### 3.2 产品详表（对内）

- 竞品档案 + 功能矩阵
- 对我方 backlog 的启示（跟进 / 差异化 / 放弃）
- 复盘日期与下次触发条件

## 4. Demo 主战场

审批域主竞品：`FlowApprove`；Agent 平台参照：`AgentForge`。
